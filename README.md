# 🗡️ Zelda — A 2D Adventure


*A classic adventure reimagined in a 2D pixel-art world.*

Welcome to **Zelda 2D**, a personal game development project inspired by the original adventure spirit of The Legend of Zelda. Instead of recreating the modern 3D Nintendo experience, this project takes a different approach, bringing the adventure into a retro, 2D, pixel-style world inspired by classic games like Mario and Contra.

Explore the world, face enemies, discover new areas, and progress through levels as the adventure unfolds.

For me, this project is more than just a game. It was my **first major solo project during my first year of B.Tech**, when I was beginning to explore programming and game development. It holds a special place in my journey as a developer.

## 🌟 About the Project

Zelda 2D is a fan-inspired, 2D action-adventure game built around the charm of classic pixel-style games.

The project takes inspiration from the world and adventure concept of Zelda while presenting its own 2D interpretation through pixel-shaped characters, graphical assets, maps, and progressive levels.

The goal was to explore how a recognizable adventure-game experience could be represented through a simpler, retro-inspired visual style while learning the fundamentals of game development along the way.

## ✨ Features

- 🎮 **Classic 2D Gameplay** — An adventure experience inspired by the original Zelda series.
- 🟩 **Retro Pixel-Style Characters** — 2D characters inspired by the visual style of classic games such as Mario and Contra.
- 🗺️ **Game Maps** — Dedicated map resources for the game's world and environments.
- 📈 **Progressive Adventure** — Levels designed around the progression of the story.
- 🎨 **Custom Graphics** — Organized graphical assets supporting the game's 2D visual identity.
- 🔊 **Audio Resources** — A dedicated collection of audio assets for the game.
- 🧑‍💻 **Solo Development** — Designed and developed independently as a first-year B.Tech project.

## 🕹️ Gameplay Concept

The game follows an adventure-oriented structure inspired by classic action-adventure titles.

As the player progresses through the story, the adventure moves forward through different levels and environments. The 2D presentation gives the game a nostalgic arcade feel while preserving the exploration-focused spirit that inspired the project.

**The idea:** take the feeling of a classic adventure and reinterpret it through the simplicity and charm of retro 2D games.

## 🎨 Visual Style

The visual direction is inspired by the 8-bit and 16-bit era of gaming, where expressive characters, recognizable environments, and simple visual designs created memorable experiences.

The project uses:

- 2D character designs
- Pixel-inspired graphics
- Separate map and graphics resources
- A retro arcade-inspired presentation

Rather than recreating the 3D Nintendo titles, this project explores a 2D interpretation of the Zelda adventure concept.

## 🛠️ Technologies and Assets

The repository is organized into separate resource directories:

- **`audio/`** — Audio assets
- **`code/`** — Game source code
- **`graphics/`** — Visual and character assets
- **`map/`** — Map and level resources

The exact programming language, framework, and runtime requirements depend on the implementation in the `code/` directory.
